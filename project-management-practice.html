Section 15.2 · Written Response1 point

Explain why over-allocating tasks to a single human resource harms project success.

Please write an attempt first before revealing the answer.

Syllabus Answer: If too many tasks are allocated to one person simultaneously, they cannot complete them on schedule. The team member becomes stressed, rushes the work, and delivers tasks to an inferior or poor standard.

Section 15.3 · Network Calculation2 points

Consider a project network where Task M takes 4 days with no dependencies. Task N (3 days) and Task P (7 days) both depend on M. Task Q (2 days) depends on both N and P.

Please write an attempt first before revealing the answer.

Worked Calculation: Path 1 (M → N → Q) = 4 + 3 + 2 = 9 days.
Path 2 (M → P → Q) = 4 + 7 + 2 = 13 days.
Critical Path: M → P → Q (length: 13 days).
Float task: Task N has 4 days of float (Task P finishes on Day 11; Task N finishes on Day 7; 11 − 7 = 4 days).
