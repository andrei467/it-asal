Protocols, Wireless and Security

This page covers network protocols and how data is switched and routed, wireless and mobile communication, satellites and GPS, network security threats and defences, and disaster recovery management.

Network protocols 14.6

Protocols are instructions for how different computers in a network communicate with each other. They are essential to ensure data is transferred efficiently and securely across a network.

Purposes and uses of protocols

Protocols are a set of rules that govern how data is formatted and processed, and allow computers to communicate with each other regardless of the software and hardware differences they may have.

ProtocolFunction
Transmission control protocol (TCP)Allows two computers to establish a connection.
Internet protocol (IP)Sets out rules for communicating over the internet. TCP/IP are mentioned together because they were designed to complement each other. IP sets the rules for the transmission of data but cannot error check the packets; TCP provides reliable, ordered and error-checked delivery of the packets.
Internet control message protocol (ICMP)An error reporting protocol used to generate error messages to send to the sender when network problems cause delivery problems with data packets.

Inverse address resolution protocol (InARP)Performs the opposite role to ARP: it translates a MAC address into an IP address.
Dynamic host configuration protocol (DHCP)A network management protocol used to assign IP addresses to devices on a network, so a network administrator does not need to do it manually.
User datagram protocol (UDP)Often used for time-sensitive communication such as video playback. It does not formally establish a connection before data is sent, so packets go directly to their target without checking the order of the packets or whether they have arrived safely, which makes it quite unreliable.
Hypertext transfer protocols (HTTP and HTTPS)HTTP is used for transferring the content of web pages across the internet, from a web server to a browser. HTTPS is the secure version of HTTP that uses the SSL protocol.

Secure sockets layer (SSL)Ensures connections between web clients (such as user devices) and web/mail servers are secure, using both public and private keys to encrypt the data. Still used in some applications but now mostly replaced by TLS.
Transport layer security (TLS)The updated version of SSL, which uses updated and more secure encryption algorithms.

Methods of sending data over a network

Transmitting data packets across a network is called switching. There are three main types: packet switching, circuit switching and message switching.

Packet switching

Instead of being sent bit by bit, data is normally transmitted across networks in small bundles, or packets. Packets vary depending on the type of network (a packet sent over the internet contains more elements to allow it to be directed to the right place), but most contain at least a header, a payload and a trailer. You could think of packets as separate envelopes, each with a stamp, an address and a letter inside.

The structure of a data packet: a header, a payload and a trailer. The header and trailer help make sure the payload arrives at its destination without errors.

The header includes the sender's source IP address, the destination IP address, the sequence number (so the receiving device can reorder the packets to obtain the original data), the MAC addresses (if the packet passes through a router these are removed, as they are only used by a switch) and any protocols used. The payload is the actual data from the file being transmitted. The trailer includes a flag telling a device it has reached the end of the packet, and any error checking methods used. The data in the header and trailer is designed to make sure the payload arrives at its destination without errors.

In packet switching, packets can take any available path. There is no set pathway and each packet could be sent along a different route, for example via any of the switches in the network. The packets are collated and reordered when they reach Computer B. It is normally used when packets are sent across the internet, via routers.

There are two modes of transmission. In connection mode (virtual circuit switching), a session is created before any data is transferred and becomes a fixed channel for the data. In connectionless mode (datagram switching), there does not need to be any prior arrangement between devices. Frame relay and TCP are connection types; Ethernet, IP and UDP are connectionless types.

If an error is detected in a frame, it is dropped and the endpoint devices detect the dropped frames and retransmit them, so it suits data where the error rate is likely to be low. Permanent virtual circuits (PVC) are intended to exist for long periods, even when no data is being exchanged; switched virtual circuits (SVC) are temporary and exist for a single session.

Circuit switching

A direct path is created between the sending and receiving device, and the data is transmitted each time using this dedicated path. While data is being transmitted from Computer A to Computer B, no other computers in the network can use the same pathway. When the transmission is completed, the path is released for use by other data transmission across the network.

Circuit switching. A direct path (gold) is created between Computer A and Computer B, and no other computer can use it until the transmission is complete.

Message switching

Message switching is an intermediate method between circuit switching and packet switching. It is like circuit switching in that all the data packets are sent along the same path, and like packet switching in that any path from Computer A to Computer B can be taken. The packets are sent from Computer A to the first switch, which holds them until all of them have arrived, and then sends them to the next switch, which also holds them until all have arrived. They are sent from switch to switch in this way until they reach Computer B. This is the store and forward method.

Network addressing systems

IP addresses are unique identifiers given to a device on a network. There are two versions: IP4, the original, is a 32-bit numerical address. As more devices connected to the internet, we started to run out of combinations, so IP6 was developed: a 128-bit address that allows many more combinations.

An IP address can be static (the device will always have the same IP address) or dynamic (the IP address could change for each internet session). Most devices use a dynamic IP address, and a user will normally need to request a static IP address from the internet provider.

A MAC address is a unique number assigned to each network interface controller (NIC), the circuit board inside a computer that enables it to be connected to a network. Although a device's dynamic IP address changes depending on the network currently being used, a MAC address is specific and unique to the device.

Static and dynamic routing

Routers use routing tables to work out the most efficient path for network traffic to reach its destination. A routing table is stored on the router and lists all the available routes to particular network destinations. Routers use routing protocols to specify how they communicate with each other, and these help select the route that data travels.

  • Static routing is used when there is a single or preferred route for network traffic. The route is preconfigured (arranged in a set way), using small routing tables.
  • Dynamic routing uses algorithms to compute multiple different routes for network traffic and decide the best one.

Functions of routing protocols

  • Interior gateway protocols specify how routers communicate with each other within a network, such as a LAN.
  • Exterior gateway protocols specify how routers communicate with each other between different networks.
  • Border gateway protocols are a specific kind of exterior gateway protocol that manage the process of exchanging packets of data across the largest network, the internet.

Use of protocol layering

There are two main network models that many networks are built on: the TCP/IP suite and the OSI model (open systems interconnection). Both outline rules and standards about how communications should take place over a network, and each is split into layers so that each layer can operate independently of another, which allows the functions at each layer to be easily adapted.

Did you know?

In 1969, ARPANET was one of the first networks created, and one of the first to use the TCP/IP protocol suite. Many consider ARPANET to have influenced the internet we know today.

The seven OSI layers and how they map onto the four layers of the TCP/IP suite.

OSI layerFunction
ApplicationThe top layer, which directly interacts with data from the user. Software applications such as web applications and email clients rely on it to communicate (user applications such as word processors are not included). It manages protocols such as HTTP and SMTP.
PresentationPrepares data ready for use in the application layer: translation (into a form the receiving device understands), encryption (decrypting received data) and compression to increase the speed of transmission.
SessionA session is the time between a communication link being opened and closed. The session layer makes sure it stays open long enough for all the data to be transmitted and then closes it immediately afterwards.
TransportBreaks down the data from the session layer into segments and gives them to the network layer; reassembles segments at the receiving device. Responsible for flow control (the best speed for transmission) and error checking, requesting a retransmission if the data is not complete.
NetworkBreaks the segments down into data packets and reassembles them after transmission. Responsible for routing: finding the best path across the network, from network to network. A router is a key component in this layer.
Data linkSimilar to the network layer, but transmits data from node to node within a network. Converts the packets from the network layer into frames. A switch is a key component in this layer.
PhysicalThe physical equipment used to transmit the data, such as the cables. Data is broken down into bits to be transmitted as binary, and the bits are reassembled into frames after transmission.
TCP/IP layerFunction
ApplicationCondenses the roles of the application, presentation and session layers of the OSI model. Uses protocols including HTTP, SMTP, POP and FTP to provide a standardised exchange of data.
TransportComparable to the OSI transport layer: maintains end-to-end communications between devices. Two main protocols: TCP and UDP.
NetworkAlso known as the internet layer; comparable to the OSI network layer. Breaks data down into packets and transmits it from network to network. Two main protocols: IP and ICMP.
LinkAlso known as the physical layer; merges the roles of the data link layer and physical layer of the OSI model. A protocol used at this level is ARP.

The OSI model is a logical model that can be applied when creating a network. The TCP/IP suite is a condensed version of it, with four layers rather than seven. It was developed by the US Department of Defense and is intended to be a more advanced version of the OSI model.

Wireless technology 14.7

Telecommunications

Telecommunications (often shortened to telecoms) is the transmission of information instantly over long distances, such as a phone call. It includes phones, cellphones/mobile phones, satellites, radio and the internet. Post or mail is not telecommunications, because the information is not received instantly. Data is transferred via telecommunications circuits. A single circuit comprises two stations, and each station has a receiver (which receives data) and a transmitter (which sends data). The signals can be transmitted via wire, cables, optical fibre, or wirelessly through electromagnetic fields or light.

Methods of wireless data transmission

Wireless methods that can be used to connect devices in a network include Wi-Fi, Bluetooth, infrared, microwaves, radio and near field communication.

Wi-Fi

Wi-Fi uses radio signals and is the most commonly used wireless communication method. Each device that wants to make a wireless connection broadcasts a radio signal, which a router or WAP receives and processes. The router or WAP also broadcasts radio signals that are received and processed by each device when it is receiving data. Wi-Fi currently transmits data at frequencies of 2.4 GHz and 5 GHz, much higher than those used by mobile networks. These high frequencies are required to send larger amounts of data. The current limit for Wi-Fi data transmission is approximately 450 Mbps.

Bluetooth

Bluetooth also uses radio signals to create a wireless connection between two devices, at the radio frequency 2.45 GHz. Devices need to be within 10 m of each other, and there is a limit of eight devices connected at any given time.

The two devices must have matching profiles: a set of rules that allow devices to complete a specific task. For example, a mobile phone and a headset share the profile that allows sound to be transmitted, so they can be paired. The profile system stops pointless connections: a wireless mouse and a digital camera do not have the same profiles and cannot be paired, because the mouse cannot be used to control the camera.

To create a connection, the Bluetooth transmitter is turned on in a device and begins to transmit radio signals. Any device with a matching profile, within range, picks up the signals and identifies with the sender as a possible device to connect to. The required device can then be chosen and the devices are paired. Sometimes pairing requires entering a pin code for added security. For example, to send a photo your phone transmits a radio signal to a receiving phone with Bluetooth switched on; you select the correct device from the menu, and the recipient gets a notification asking if they wish to accept the photo.

Infrared

Infrared connections use infrared radiation, in two modes. In line-of-sight mode, there must be a direct line of sight between the sending and receiving device, with no obstacles in the way. In scatter mode, a device broadcasts infrared into an area and any device may receive it directly or through reflection off an obstacle. The sending device needs the ability to produce an infrared signal, and the receiving device needs an infrared sensor to capture it.

Infrared lasers can also transmit data between devices. Laser data transmission works in a similar way to fibre optic, using the properties of light, but rather than travelling through physical transmission media it travels through free space.

Microwaves and radio waves

The terms are often used interchangeably, because both are types of electromagnetic radiation that can be used to transmit data and power. Microwaves have shorter wavelengths and are generally used for short-distance communications; radio waves have longer wavelengths and are generally used for long-distance communications. The waves used in both Wi-Fi and Bluetooth are technically microwaves, but historically the term 'radio waves' has been applied to the technology used in wireless data transmission.

Near field communication (NFC)

NFC allows devices near each other to communicate without the need for an internet connection. An NFC chip is one part of a wireless link. Once activated by another chip, small packets of data can be shared or transferred when the devices are held no more than a few centimetres from each other. There is no pairing code or internet connection required, because NFCs use chips that run on small amounts of power. An example is contactless payment through your phone or watch.

The Internet of Things

The Internet of Things (IoT) connects devices over the internet, allowing them to share data. It is a system of connected devices, such as smart phones, smart watches and smart technology such as smart heaters in our homes, enabling them to collect and exchange data. It gives us the ability to connect objects that have historically not been connected, such as weather stations and phones, or mail boxes and watches. The devices often rely on wireless transmission methods like Wi-Fi: for example, via Wi-Fi you can use your phone to control your thermostat at home. Access to wireless transmission has meant that the IoT has gained traction as a concept in recent years.

Security issues

Wireless connections do not have the same level of protection as a wired connection. Wired networks are normally limited to a building or single site, often with locks and other security methods to stop an unauthorised person entering the area and gaining access. Two main protocols improve the security of a wireless network:

  • Wired equivalent privacy (WEP) is designed to provide a wireless network with a similar level of security to a wired LAN, by encrypting data transmissions sent using a wireless connection.
  • Wi-Fi protected access (WPA) is a standard required of devices equipped with a wireless internet connection, designed to provide a more sophisticated encryption method than WEP.
  • Firewalls can be configured to control access to networks, by setting rules about which stations on a network can send or receive packets, or by limiting which devices can join a network.

Other preventative security methods, such as strong passwords and good practice, apply to wireless connections too.

Mobile communications systems 14.8

Cellular networks

Mobile networks are broken down into small areas called cells. At the centre of each cell is a radio base station that transmits and receives messages. The base stations connect to public telecommunications services, allowing access to the internet. This is where the term 'cellphone' in American English comes from.

A mobile (cellular) network is divided into cells. Each cell has its own base station with a low-power transmitter, and neighbouring cells use different frequencies so the same frequencies can be reused further away.

Cells vary in size:

  • picocells cover an area of less than 200 metres
  • microcells cover an area up to 2 kilometres
  • macrocells cover larger regions

There have been several generations of mobile networks, each providing faster access speeds and greater reliability:

GenerationDescription

How satellite communication systems transfer data

A communications satellite is a machine transported into space and set to orbit the Earth. Satellites transmit radio waves from one place on Earth to another, which can carry most things radio waves on Earth are used for, including telephone calls, internet data and television broadcasts. Satellites are complex machinery; their main components are a solar powered battery, a transponder and various antennas.

Any data to be sent using satellite communications needs to be converted to radio waves. The data is transmitted as radio waves from a ground station on Earth; this is the uplink. The radio waves travel through the atmosphere up to the intended satellite (a chosen satellite, or the nearest in orbit). The antennas on the satellite initially receive the radio waves. The transponder processes the data, which can often involve boosting the signal. The antenna then transmits the radio waves back to the destination ground station on Earth; this is the downlink.

A ground station uploads (transmits) a signal to a satellite, which sends it down to another ground station.

Global positioning systems (GPS)

Satellites are also used in navigation systems such as GPS, which uses satellites to work out a user's current location.

Did you know?

One of the most well-known satellite navigation systems is the Navstar GPS, which has 24 satellites in orbit. At any time on Earth, a user will usually be in the line of sight of at least ten of these satellites, but only three or four are needed to work out a user's location.

A process called triangulation (pinpointing the location of a device using radio signals from a satellite) finds the location of a user. Each navigation satellite constantly beams radio waves towards Earth, and the user's device, such as a mobile telephone, receives them. A device must pick up radio waves from at least three satellites for the GPS to pinpoint the location. If the device receives a signal from satellite A, the user must be somewhere in the area currently covered by satellite A. If it also receives signals from satellites B and C, the user must be at the point where the areas covered by all three satellites meet.

A device is a known distance from each of three satellites. Where the three circles meet is the device's position (trilateration).

Global mapping systems

Web mapping platforms (global mapping systems) offer satellite imagery, street maps, aerial photography and sometimes street views of the entire planet. They can be used for route planning, including information on when and where you can catch a bus or train. Google Maps maps the Earth by superimposing satellite images and aerial photography onto a 3D globe, allowing users to see a birds-eye view of locations. The satellite images are collected by purpose-built imaging satellites. Their resolutions vary, so the images are often supplemented with aerial photography, which is higher resolution but more expensive per square metre.

Surveillance

Many devices are equipped with GPS, including mobile telephones and cars. As well as letting the user find their location, this technology can be used by others for surveillance. It is possible to use a GPS to find out where another person is by tracking their device. These devices often keep a log of all GPS activity, so it is possible for a person to gain access to that log and see exactly where the device (and therefore possibly the user) has been.

Ultra-high-definition television

Satellites are used in broadcasting ultra-high-definition TV (UHD TV), which needs a lot of bandwidth to sustain the quality. Satellites, with their large bandwidth availability and wide coverage, allow viewers to receive consistent quality wherever they are, as long as they are within the satellite coverage. The UHD TV signal is caught and reflected back to the satellite dish, then connected with coaxial cables that feed the UHD TV receiver.

Network security 14.9

Network security threats

Data is an organisation's or individual's most important asset, which makes it vulnerable to theft and misuse. There are a range of network security threats.

Brute force. Individuals may try to break into a computer system to gain unauthorised access. This may involve stealing a user's login details and then guessing their password using many different possible combinations, or building software that can work out the password. Obtaining unauthorised access in this way is a brute force attack. Users or organisations with poor network policies are often most at risk. Using strong passwords generated by a password manager can help reduce the risk.

Denial of service. A distributed denial of service (DDoS) attack is a cyber attack that overwhelms a website with traffic, usually across many devices, with the intention of taking the website offline. It can be a form of protest against an organisation. A website going offline, even temporarily, can affect sales by blocking access of legitimate customers, damage reputation and damage the distribution of a message or campaign.

Malware is any software designed to disrupt or damage a computer system or gain unauthorised access. It includes worms, spyware and ransomware. A user will normally unknowingly download the malware onto their computer; it is often disguised in a file download or a link that the user is enticed into clicking.

Botnets. An attack may come from a single third party and computer, or be distributed across many computers. A botnet is a group of computers controlled by software to perform harmful acts. Any user's computer could be made part of a botnet, often by downloading malware, which will often stay dormant until the third party wants to use the computer in an attack. Each infected computer is called a bot. When the attacker wants to carry out an attack, they 'wake up' the malware in the bots and use them to form a botnet, which can carry out attacks such as a DDoS attack.

Malicious actors. People who steal data to use it for criminal activity such as identity theft, or to cause damage to data and therefore to the company, are called malicious actors (perpetrators): a group or entity whose mission is to affect or cause harm in the digital world, performing deliberately hurtful acts against individuals or organisations, usually with a personal agenda. The use of networks has made accessing data through malicious means a greater risk.

Structured query language (SQL) injection. SQL is a programming language used to maintain databases. An SQL injection is a technique used to destroy, modify or retrieve data. By inserting SQL code as data, an attacker can execute commands that retrieve data from the database. SQL injections usually happen over the internet, and the result can be the destruction of important data or other problematic behaviours. In its most extreme form, an SQL injection can give an attacker complete control of a device.

Poor network policies may increase the likelihood of an attack on a network. As well as using a password manager, individuals and organisations can put a range of other preventative methods in place to help protect their data.

Impact of network security threats

There are two main reasons why unauthorised users carry out security attacks: to obtain personal data, or as an act of sabotage or revenge.

  • Individuals need to be cautious of their personal data being accessed and stolen, which could lead to criminal acts such as fraud and theft of their identity, in turn leading to financial or personal consequences.
  • Organisations need to be cautious of their stored data being accessed and stolen, or manipulated, modified and destroyed. Data is a very important asset used in the day-to-day functioning of the organisation, and without it they are unlikely to be able to function at all. Not being in operation could lead to a loss of business and profits. If data is stolen because security has been breached, this could also damage the organisation's reputation.

Methods of preventing network security issues

Physical methods

The simplest way to protect data is to use physical methods. Organisations can install a digital door lock or entry system so that only employees who know the code or have a door pass can enter. Other physical methods are CCTV (lets an organisation see who is trying to gain unauthorised access), security guards (should allow only authorised users into a place where data is stored, for example a server room) and alarm systems (alert the organisation if an unauthorised person tries to gain access).

Software methods

MethodHow it prevents unauthorised access
Biometric methodsAn employee provides biometric data such as a fingerprint, iris or facial features. A biometric device scans it and checks whether it matches data stored in a database; if it does, the employee is allowed access. Biological data is unique to the user and very difficult to fake. Modern mobile telephones have biometric devices to secure the device.
Anti-malware, anti-virus and anti-spywareScans a computer system for malware. If it finds malicious files, it quarantines the malware (puts it in a designated safe area) and allows the user to delete it. It can sometimes monitor downloaded data in real time, scanning each download and alerting the user before the file is downloaded. The quicker malware is found, the less damage it can do.
FirewallCan be hardware based or software based. It examines incoming and outgoing traffic to a computer or network. It can be configured (set) to recognise malicious traffic by giving it rules and criteria to check the traffic; traffic that does not meet them can be rejected.
EncryptionWill not stop the data from being stolen, but if it is stolen it will be meaningless to the third party, unless they are able to get the key to decrypt it.
Access rightsOnly allowing access to those who directly need the data. The username an employee is given often indicates their access rights, and permission to access the data they need is attached to it, so they cannot see data that needs to remain confidential. This can prevent data being damaged.

Disaster recovery management 14.10

In an organisation, a disaster is anything that may put the operations of the organisation at risk through data loss and business disruption. Disaster recovery is a planning process that allows an organisation to plan for disaster and put in place measures that will minimise the risks. To plan for protection against a disaster, the possible disaster first needs to be identified. Disasters include:

  • cybercrime or malware infection, which can block access to a computer and data
  • equipment or power failure, which can result in the loss of work/data
  • natural disasters, which may result in the loss of equipment or data
  • criminal activity, such as theft
  • accidental events that disrupt standard practice, such as dropping equipment or spilling a drink over a keyboard or tower

Identification of threats and risks

There are several stages that can be used to identify threats and risks that could cause a disaster:

StageDescription
Risk analysisAlso known as a risk assessment. The organisation first identifies what could be a potential disaster, then considers what or who could be harmed as a result and how it could affect the organisation. Finally they develop methods to control the possibility and impact of the disaster. All parts of a company are assessed, including its infrastructure, networks, hardware, software and people. Things that could cause disaster include a power cut, cybercrime, fire, flood, denial of access to data, theft of data, corruption of data and hardware failure.
Perpetrator analysisOften carried out as part of the risk analysis. The organisation identifies who they think could be a perpetrator that could cause a disaster to occur.
Risk testingThe organisation rehearses the plans and strategies developed during the risk analysis, so employees understand exactly what to do in the event of a disaster. The organisation can monitor what happens during testing and amend plans, or correct employees' behaviour. Plans that could be tested: restoration of data; replacement of hardware; re-installation of software; emergency evacuation of offices; emergency protection methods for data.
Quantifying the riskEvaluating the risk and prevention methods in terms of cost and time. Two key measurements: maximum tolerable downtime (MTD), the maximum time each part of the organisation could tolerate not having access to the essential parts of a network that they require; and recovery time objective (RTO), the estimated maximum amount of time an organisation has in which to recover its network and resume operations.

Control of threats

In the event of a disaster, data and resources will need to be restored. This can often mean the restoration of data from back-ups, the re-installation of software, and the replacement or repair of hardware. All these areas are planned and assessed in a disaster recovery plan, which considers how they will be carried out and what timescales to expect.

Organisations and individuals also need to be able to detect potential threats that may cause disruption. For example, an organisation in a region vulnerable to flooding or earthquake may have protocols to protect their computer systems, data and files if a threat is imminent, and may regularly review their network practice to make sure it is as robust as possible.

Strategies to minimise risk

As well as the methods to protect data and a network against cybercrime, an organisation needs methods to prevent against other disasters. Strategies include:

  • Power surge protection devices to stop a surge in power damaging hardware.
  • A back-up generator ready for use if the organisation suffers power failure.
  • Back-ups of data stored in fire and flood proof cases so that data is not lost in a fire or flood. Back-ups could also be stored off site, as long as they are kept away from the site of the threat (for example external hard drives and memory cards).
  • Policies and procedures for staff to follow to prevent disaster such as fire and damage to equipment.
  • Cloud computing as a back-up for data and possible hardware resources.
