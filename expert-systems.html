Expert Systems

This page covers what expert systems are and the components they use, real-world scenarios where they support decision making, forward and backward chaining in the inference engine, and the advantages and disadvantages of expert systems.

Components of an expert system 7.1

Introduction

You spend time every day developing your knowledge, thinking and making decisions. It is possible to develop computerised systems to aid decision-making processes. These are called expert systems.

An expert system is a computerised system that attempts to reproduce the decision-making process of an expert human being. Expert systems are designed to try to replicate the judgement of a human that has expert knowledge in a certain field. By doing this, expert systems can be used to replace or assist a human expert. The person who designs and develops an expert system is called an expert system engineer.

An expert system operates by prompting the user to enter certain data using the user interface, referring to the knowledge base and using the inference engine to aid the decision-making process it is designed to support.

Expert systems can be used in many different scenarios — settings where expert systems are used for specific tasks. They can be used as a diagnostic tool, such as in financial planning and risk analysis, or even for a more fun purpose, such as playing Scrabble online against a computer. They are also a form of artificial intelligence, which is a computer system designed to simulate human intelligence.

The five core components

An expert system consists of several interrelated components:

  • a user interface
  • a knowledge base (made up of a database of facts and a rules base)
  • an inference engine
  • an explanation system
  • a knowledge base editor

Architecture of an expert system showing how the five components interrelate.

User interface

The user interface is the way that a user interacts with the expert system. This could include using a keyboard to enter data into text query boxes, or choosing options by pressing offered choices on a touch screen (Figure 7.1).

The user interface prompts the user for the data they need to input into the expert system and then displays any output from the expert system. Other output devices may also be available, such as a printer to produce a paper copy of results.

Without a user interface, a user would need to know how to program each of the interactions they want to make with the expert system. The quality of the design of a user interface is important to the usefulness of an expert system.

Knowledge base

The knowledge base is a component of an expert system that stores the knowledge provided by experts — a database of related information about a particular subject. It allows the storage and retrieval of the knowledge required for an expert system to operate.

When an expert system is developed, several experts are interviewed and asked to provide the knowledge they have of a given field. This knowledge is then used to build a database of facts (all information that is known about the subject within the knowledge base).

The developers want two types of knowledge from the experts:

  • Factual knowledge: knowledge that is widely shared among experts in the field.
  • Heuristic knowledge: knowledge that is built on personal experiences and reasoning.

Part of the knowledge base is the rules base — the part of the knowledge base that contains all the rules to be analysed by the expert system to produce a decision. These rules are used by the inference engine as a base for reasoning, to obtain a solution to a problem or a decision. Each rule contains two parts, IF and THEN. A rule can also have multiple IF statements joined together by Boolean operators, including AND and OR. A simple example of a rule could be:

IF a > b AND a > c THEN highest = a

The knowledge base should be regularly updated. Because of this, the expert system needs to have a knowledge base editor — a component used to change or update the knowledge base. The knowledge base editor allows the knowledge base to be edited and added to when necessary.

Inference engine

The inference engine is the part of the expert system that makes judgements and reasoning using the knowledge base and user responses. It is designed to produce reasoning based on the rules base and the knowledge base.

The inference engine asks the user questions and, based on their answer, follows a line of logic. This may then lead to further questions and, eventually, to a final result.

Explanation system

The conclusion or decision the expert system provides may not always be an obvious choice to a user. The user may therefore want to gain an understanding of how the conclusion or decision was made. To provide this information, some expert systems have an explanation system built into them — a component that provides an explanation of the reasoning process and shows how the output given by the system was reached.

How are expert systems used? 7.2

Expert systems are used in a range of scenarios by individuals and organisations to support decision making. Expert systems may be used in:

  • medical diagnosis
  • car engine fault diagnosis
  • providing financial planning and investment analysis
  • providing insurance planning advice
  • plant and animal identification
  • scheduling routes for delivery vehicles
  • mineral prospecting

Medical diagnosis

The organisation WebMD has a website that offers a medical expert system called 'symptom checker'. It asks the user a series of questions about their symptoms and then provides possible conditions that match the symptoms. It lists the possible conditions in order, starting with the one it finds to be the closest match.

Car engine fault diagnosis

Most modern cars have lots of technology built into them, including an on-board expert system known as the on-board diagnostics system. It monitors the car's engine performance. If the engine develops a fault, the diagnostics system turns on a warning light on the dashboard to alert the driver. When the driver sees the warning light, they should take the car to a garage. At the garage, a mechanic connects a diagnostic tool to the on-board diagnostics system (Figure 7.2). The expert system provides the mechanic with a code that helps them to find and fix the fault.

Did you know? — Diagnostic Trouble Codes (DTC) & Activity 7.03 (Deep Blue & AlphaZero)

Diagnostic Trouble Codes: When a car mechanic connects a diagnostic tool to the on-board diagnostic system, they are given a five-digit Diagnostic Trouble Code (DTC). There are thousands of possible DTCs, including some that are specific to different manufacturers.

Activity 7.03 — Chess Systems: In 1997, the expert system Deep Blue beat the world champion chess player Garry Kasparov (Figure 7.3). Modern systems such as AlphaZero also demonstrate how AI and rule/search-based systems can defeat world-champion human players.

Financial planning and investment analysis

Expert systems can be a useful tool in financial planning for both individuals and businesses. They can create a financial plan or assess what financial actions need to be taken to achieve a desired outcome. They can help people to:

  • manage their debt
  • reduce their outgoings
  • reduce their taxes
  • plan for retirement

A user enters information about their financial situation and personal circumstances. The expert system then produces a financial plan, or a list of possible outcomes, based on this information.

Expert systems can also be used to analyse investments and help maximise returns on funds invested. They can help people to:

  • monitor stock markets and suggest when to buy and sell shares
  • determine how much risk is involved with certain investments
  • make decisions based on the amount of money they wish to invest
  • examine options on the period of time to invest their money, for example 1–5 years
  • decide whether to move from one type of investment to another

Using such systems, sometimes with the support of a professional financial adviser, enables people to make informed decisions based on the information provided.

Insurance planning

Many insurance company websites use an online expert system so that users can quickly see if the company has a policy that would be suitable for them. Such systems ask the user for relevant personal information and then provide a result to say whether the insurance company would be willing to give the user an insurance policy. If the expert system is able to match their data to a possible policy, it informs the user with details about the policy, such as how much it will cost and what benefits it will provide.

Plant and animal identification

The Native Plants Database, provided by the University of Texas in Austin, allows users to enter a range of characteristics about a plant (mostly covering native plants in North America). The website takes the data input about the plant and analyses it against its rules and knowledge base. It then tells the user what kind of plant it could be, with further options provided to offer more specific results if required. A user could find out what kind of plant is growing in their garden, or try to discover the type of plant they have seen when on a walk (Figure 7.4).

Expert systems are also available to enable users to identify animals — for example, inputting data based on an animal's characteristics to determine what animal it might be.

Route scheduling for delivery vehicles

Delivery companies can use expert systems to find out the best route for a delivery driver. The expert system helps determine the most efficient route, such as the shortest distance or quickest time, for all the deliveries the driver has on a given day.

Each of the deliveries the driver needs to make is put into the system, which then outputs the most efficient route to follow. It may request further information, such as the type of delivery vehicle and how long each delivery will take. The system may make further recommendations about how many drivers are needed to deliver all the items that day and what kind of vehicle each driver will need to take for the packages they need to deliver. An expert system can work out this type of outcome quicker than a human due to the amount of data it handles, especially in large delivery companies where multiple vehicles are used at the same time (Figure 7.5).

Mineral prospecting

Minerals like ruby, emerald and iron can be very precious, and geologists can spend a long time trying to source them (Figure 7.6). Digging for minerals can be very expensive, so companies want to be sure that minerals will be present when they break ground (Figure 7.7).

An expert system called PROSPECTOR was one of the first expert systems developed to aid geologists in exploring for minerals. PROSPECTOR can be used to calculate the probability of minerals being present in a certain location by examining data related to factors such as the soil type and topography of the land.

Backward chaining and forward chaining 7.3

There are two main methods that an inference engine can use to simulate reasoning: backward chaining and forward chaining. IF…THEN constructs are used to determine whether a rule is true when using these methods.

Backward chaining

Backward chaining is based on goal driven reasoning, where reasoning is dependent on finding a desired goal. This type of chaining is used when the possible outcomes are limited and clearly defined. In backward chaining, the system takes a goal and repeatedly splits it into sub-goals that are simpler to achieve. This type of system moves backwards from the goal to be achieved, using the sub-goals to inform the next piece of data that is needed by the system to reach a goal.

For example, within a video game, an expert system might be used to determine whether a player can progress to a certain area (the goal). Backward chaining could be used to check IF the player has collected certain items, such as a key, AND IF they have defeated a specific enemy, such as a robot spider (sub-goals). Should both these facts be true, THEN the player can move on to the next part of the game.

Figure 7.8: Example of backward chaining used in gaming (working backwards from the goal into sub-goals).

Forward chaining

Forward chaining is based on data driven reasoning and is dependent on the data that the expert system is provided with. This type of system is used when a problem is more open ended, and the outcome is not always clearly defined. The system takes data input by the user and moves forward from rule to rule to suggest possible outcomes where the rule for the data input is true. It then asks the user for more data and repeats this process until it can suggest an outcome.

For example, when a doctor is deciding on a diagnosis for a patient, they input data prompted by the expert system, such as IF the patient is over a certain age. Should the patient be older than the age specified, such as over 65 years, THEN further questions will be asked appropriate to that age group, such as if they have mobility needs. Different questions could be asked if the patient is the same age or younger than the age specified.

Figure 7.9: Example of forward chaining used in diagnosis (moving forward from user data through rules).

Artificial intelligence and social media

Data-driven artificial intelligence (AI) may be used to manipulate social media. Social networking platforms can use data related to the user's behaviour — such as videos viewed, group membership and adverts clicked on — to change the content provided to individuals.

Through manipulating the content shown to a user, AI can be used to ensure only certain viewpoints are presented, which may influence the user's point of view and decision making. Using data in this way may result in users being presented with false or misleading information, potentially allowing their views to be manipulated.

Advantages and disadvantages of expert systems 7.4

Table 7.1 sets out the possible advantages and disadvantages of using an expert system.

Advantages

  • Can provide answers to questions that are outside the knowledge that you currently have.
  • Can aid professional people by prompting and guiding them to look at areas of knowledge they may not have considered or remembered.
  • Are consistent in the responses they produce as they are arrived at in a logical way.
  • Can be used at any time, so you do not need to contact another person who may have the knowledge, yet be unavailable.
  • Can explain how they have arrived at a decision through displaying the logic used.
  • Can sometimes arrive at a solution to a problem quicker than a human would.

Disadvantages

  • Do not have the intuition that humans have. This means that their response can only be a logical one and may not be useful.
  • Are only as good as the rules and data they are provided with. If there are errors in the data or rules, such as if the data or rules need to be updated, then this will produce incorrect results.
  • Are expensive to create and maintain. Many experts need to be consulted and a high level of skill is required to build the component parts, along with keeping the system up to date.
  • Cannot adapt to new or extraordinary situations and may require the knowledge base to be edited in order to do this.
Discussion point

How do you feel about the use of expert systems to make decisions, or for planning, in your own life? Consider when you would trust an automated logical system (such as route planning or checking insurance quotes) versus when you would prefer human intuition and empathy (such as complex medical or personal decisions).
