Cambridge AS & A Level IT · Chapter 14 Communications Technology

Networks & Infrastructure

How networks are built: the types of network, the hardware that connects them, the servers that run on them, and cloud computing as an alternative to owning it all yourself.

Networks 14.1

A network is two or more computers or devices connected together so they can communicate and share data and resources.

Local Area Network (LAN)

A LAN is a network limited to a small geographic area, such as a single building, a campus, or a group of closely located buildings.

  • High data transfer speeds, up to around 1 GB per second
  • Fewer transmission errors, because data travels only a short distance
  • Normally connected using copper wire, fibre optic cable or radio waves
  • Can be kept more secure, since fewer devices need securing, and the owner is responsible for that security
  • Usually privately owned — set up and maintained by a single organisation or individual, such as a business, school or government body, which controls its configuration and security

Advantages

  • Efficient sharing of files, printers and applications
  • Reduces costs by cutting the need for duplicate equipment
  • High data transfer rates allow fast communication and data exchange
  • Highly scalable — new devices can be added as the network grows
  • Supports centralised data storage and management on servers, for better organisation and security

Disadvantages

  • Initial installation and setup can be expensive
  • Limited physical range, confined to a smaller geographical area
  • Relies on centralised hardware such as servers and switches, so it's prone to failure if those central components fail
  • A virus can spread more easily, and the network is more exposed to security threats

Wide Area Network (WAN)

A WAN spans a large geographical area, connecting multiple LANs and other network devices. It can cover a single country or span several. The internet is the largest WAN.

  • Often restricted to lower transfer speeds, typically less than 200 Mbps
  • Greater chance of errors, because data travels over much longer distances
  • Connections can be physical (copper wire) or wireless (radio waves, microwaves, transmission towers, satellites)
  • More exposed to security issues, since a large number of devices need securing, and the organisation has to rely on the security measures of others for parts of the network it doesn't control
  • Elements of the network are often owned by a third party, so the organisation relies on others for control and maintenance

Advantages

  • Enables global connectivity, making communication and resource sharing easier
  • Cost efficient, since resources can be shared virtually
  • Highly scalable — can grow seamlessly with organisational expansion
  • Enables remote access

Disadvantages

  • Higher latency, since data is transmitted over long distances
  • Expensive to build and maintain, given the large geographical coverage involved
  • Much more complex to design, implement and manage than a LAN, requiring specialised expertise
  • Limited central control, since a large number of devices/users need monitoring and much of the service depends on third-party providers
  • Higher risk of unauthorised access and breaches, due to the larger network setup

Client-server networks

A client-server network contains two types of computers: clients and servers. The server (or servers) acts as a central point of control, providing a dedicated function for the network, and all other computers connect to it to use that function. Most client-server networks operate on a request-response basis: a client sends a request asking the server to perform a task, and the server responds by carrying it out.

Server typeFunction
File serverStores and manages data files, removing the need for extensive storage on client computers. Lets a user access their files and any publicly shared files from any client computer, and allows a central backup of all data.
Web serverStores, processes and transmits web pages.
Mail serverSends and receives email, storing incoming messages until the user downloads them, and forwarding outgoing messages to their destination. Most mail servers scan for known viruses, malware and spam.
Application serverInstalls and runs software applications, providing a platform for both desktop and web applications.
Print serverReceives print jobs from client computers and sends them to the correct printer. Can be set to use a specific printer, or the next available/closest one, and queues jobs when several are sent at once.
FTP serverManages file transfers using the file transfer protocol (FTP), and keeps a log of all FTP activity. Widely used for transferring files over the internet.
Proxy serverActs as an intermediary between clients and other servers, forwarding client requests on to the relevant server. Adds a layer of security by stopping clients directly accessing other servers, and can also act as a firewall.
Virtual serverShares the hardware of a physical server, created using virtualisation software. Several virtual servers can run on one physical server, and each can take on the role of any of the server types above. Hosting companies often use this to host several businesses' websites on one physical machine.

Advantages

  • Files can be kept in a single place and backed up regularly, so individual users don't need to manage this
  • Security can be controlled from a central point, rather than by each user
  • Access levels can be applied to resources and data, so only authorised users can reach confidential data
  • Software and peripheral updates can be rolled out centrally, rather than relying on each user to install them

Disadvantages

  • Can be very expensive to set up, due to the cost of equipment such as servers
  • Expensive to maintain, since specialist knowledge is needed to set up and run the servers
  • If a server fails, its function becomes unavailable to everyone — for example, no one can access their files if the file server goes down

Peer-to-peer networks

A peer-to-peer network is decentralised: every computer (a "peer") has equal status, and peers share data and resources directly with each other without needing a server. Each peer stores its own data, and can choose whether to share it with other peers or keep it private. Peers can join or leave easily, and peers with different processing power can collaborate on a task. BitTorrent is a well-known example.

In BitTorrent, peers share the workload without a central server, acting as both client and server for other peers. Several sources, known as hosts, form a swarm, each holding pieces of a file. A user joining the swarm (a peer) downloads different pieces simultaneously from various hosts, and the protocol reassembles them into the complete file; each piece is protected against modification. A user providing the file is called a seed, and once a peer has downloaded a piece, it can start seeding that piece to others. A tracker keeps a record of which peers hold which pieces, and downloads can be paused and resumed. BitTorrent is used to stream video and transfer large files using minimal bandwidth, and even by social media platforms to distribute updates across servers.

Advantages

  • Relatively cheap to set up, since there's no need for expensive servers
  • Needs little technical knowledge to set up
  • Users can share data and resources directly
  • Often generates less traffic than an equivalent client-server setup
  • Users have full control over the data stored on their own computer
  • If one peer fails, the effect on the rest of the network is minor — only that peer's shared data becomes temporarily unavailable

Disadvantages

  • A peer being accessed by others can run more slowly
  • Data isn't centrally backed up, so if a peer loses its data, it's lost for everyone unless another copy exists
  • Shared files can be disorganised and hard to navigate, since there's no central organisation
  • Each user is responsible for their own peer's security, so an unprotected computer can pass a virus on to other peers

Virtual Private Network (VPN)

A VPN is a secure technology that encrypts an internet connection, giving privacy, anonymity and secure access to remote networks. It lets a user browse privately, access geographically restricted content, and connect securely to a corporate network from anywhere.

A VPN client on the user's device encrypts their data and sends it to a VPN server, which forwards it to its real destination (and the reverse happens for the response). If the data is intercepted in transit, it's useless to the attacker because it's encrypted, and they can't tell its true origin or destination — all they see is traffic to or from the VPN server itself.

IPSec (Internet Protocol Security) is a network protocol designed to encrypt and authenticate data packets sent across the internet, and is used as part of the tunnelling process for a VPN. Encryption keys or digital certificates are used for authentication, and pre-shared keys are negotiated at the start of a session; all data exchanged during that session is encrypted. IPSec can support pre-shared-key or public/private-key encryption, and works at the internet layer, meaning the encryption happens at device level and can support VPNs directly.

Tunnelling breaks data into small packets for transfer over an IP network. These packets are encapsulated inside ordinary public IP packets by a tunnelling protocol (such as L2TP) and sent over public communication channels; the data itself may be further encrypted using SSH or IPSec. At the destination, the packets are decapsulated and decrypted.

Advantages

  • Data is encrypted before being sent across the network
  • The sender's identity is kept private from the destination, and from any hacker who intercepts the data
  • The user isn't responsible for maintaining the VPN server

Disadvantages

  • In some countries, VPN use is illegal or controversial, since it can be used to create anonymity for criminal activity
  • The security of the data depends on a third party's software and server maintenance
  • There is often a cost involved, such as a monthly subscription fee

Mobile networks

A mobile (cellular) network is a wireless WAN that uses radio waves to transmit and receive communications from portable devices such as smartphones. The network is broken into small areas called cells, each covered by a radio base station that transmits and receives messages and connects to the public telecommunications network, giving access to the internet.

There have been several generations of mobile network, each faster and more reliable than the last:

GenerationKey features
1GThe first generation, using analogue signals. Largely limited to voice calls and text messages.
2GSwitched to digital transmission, improving signal quality, and let phones connect across networks.
3GIncreased data speeds up to around 2 Mbps, enabling mobile internet access, video and online gaming.
4GData speeds up to around 1 Gbps, supporting high-quality video streaming and more advanced mobile services and gaming.
5GThe latest generation, with speeds tested up to around 1.5 Gbps (and rising). Supports AR, VR and the Internet of Things. Offers very large device capacity (up to around a million devices per km²), high bandwidth, very low latency, seamless handover between base stations, and 'beam-forming' to aim signals directly at specific devices.

Advantages

  • Let users communicate and access the internet on the move, usually via a smartphone
  • Splitting the network into cells allows lower-power transmitters to be used, saving energy and cost
  • A limited set of radio frequencies can be reused across distant cells, increasing the number of simultaneous communications possible
  • Several low-power transmitters can cover a larger area than a single high-power one, even though high-power transmitters also have a limited range

Disadvantages

  • Reception quality can vary, and can be poor towards the edge of a cell, causing interrupted or delayed transmission
  • Frequency use must be carefully planned to avoid interference between neighbouring cells
  • 5G technology is still limited in places, and it may take time and cost to make it fully usable everywhere

Components in a network 14.2

Network interface cards (NIC / WNIC)

A NIC is the essential link between a device and the network. It operates at the data link layer, encapsulating data into frames and adding source and destination MAC addresses for addressing within the local network. Every NIC has a unique MAC address that identifies the device.

  • Provides physical connectivity, whether wired (Ethernet) or wireless (Wi-Fi)
  • Prepares outgoing data by converting it into frames and transmitting them onto the network
  • Simultaneously monitors for incoming frames, processing them and passing the data to the device's operating system
  • Needs driver software to communicate properly with the operating system
  • Works alongside switches, routers and firewalls for efficient, secure communication
  • A wireless NIC (WNIC) does the same job using radio waves, working together with a wireless access point (WAP)

Repeaters

A repeater boosts a signal, extending a network's reach by amplifying and retransmitting it. It operates at the physical layer: it receives a signal, amplifies it to compensate for degradation over distance, regenerates it to remove noise, and retransmits it. Repeaters are used less often in modern networks built around switches and routers, but can still extend the reach of a network segment. Wireless repeaters amplify and retransmit Wi-Fi signals in areas with weak or no coverage. A repeater doesn't address congestion or provide network segmentation, and can introduce a small delay (latency).

Hubs

A hub connects several devices to a network when they can't all be connected via a single Ethernet link. When data needs to reach a device, the hub sends it to every connected device; the intended device accepts it, and the rest simply ignore it. This is inefficient and can weaken the signal. A hub can be passive (just forwards data to everyone) or active (also amplifies and regenerates the signal to make it stronger). A hub operates at the physical layer (layer 1) of the OSI model.

Switches

A switch is similar to a hub — it connects multiple devices — but operates at the data link layer (layer 2). It examines each packet it receives, checks the destination MAC address against a stored MAC address table, and forwards the packet only to the intended device (unrecognised traffic is sent to everyone). This reduces data collisions and gives better performance than a hub.

Wireless access points (WAP)

A WAP lets a wireless device connect to a wired network within a coverage area. It receives wireless signals and passes them onto the wired network, often via a switch. Devices with a WNIC connect using the WAP's SSID (service set identifier). Multiple devices can connect to the same WAP, effectively forming a wireless LAN, though there's usually a limit on how many. Because signal strength fades with distance, large sites often use several WAPs, sometimes coordinated by a wireless controller.

Gateways

A gateway is a device or piece of software that lets two or more different networks connect and exchange data, even when they use different protocols. A router is a common example of a gateway connecting two similar networks.

Bridges

A bridge joins separate LANs together, dividing a larger network into smaller segments to create separate collision domains and reduce the chance of data collisions. It operates at the data link layer (layer 2), filtering and forwarding traffic based on MAC addresses, and keeps its own MAC address table for each connected segment. When a packet arrives, the bridge checks it against this table: if it's addressed to another segment, the bridge forwards it there; if it belongs to the same segment, the bridge ignores it and lets it continue — much like a switch.

Routers

A router acts as a gateway connecting two or more similar networks, and assigns each connected device a unique IP address identifying its location on the network.

  • IP addresses can be IPv4 (32 bits) or IPv6 (128 bits)
  • An IP address can be static (stays the same every time the device connects) or dynamic (changes each session) — most devices use a dynamic address unless a static one is specifically requested from the internet provider
  • A router can also connect a LAN to a WAN
  • It forwards data packets by examining each packet's destination IP address
  • It keeps a routing table to work out the most efficient route for each packet, using routing protocols to help choose that route
Protocol typeRole
Interior gateway protocolSpecifies how routers communicate with each other within one network, such as a LAN.
Exterior gateway protocolSpecifies how routers communicate with each other between different networks.
Border gateway protocolA specific kind of exterior gateway protocol that manages the exchange of data packets across the largest network of all — the internet.

Firewalls

A firewall monitors and controls the traffic entering and leaving a network against a defined set of rules. It can block traffic that doesn't meet those rules, and maintain a blacklist of denied sources, refusing any data to or from them. Firewalls can also generate logs for monitoring and reporting, and some provide VPN services too. A firewall can be implemented in hardware or in software.

Each type of server introduced in 14.1 brings its own particular strengths and weaknesses.

Server farms

In a server farm, many servers work together to keep a larger infrastructure running efficiently:

  • They share the workload, so no single server becomes overloaded
  • They offer high availability — if one server has problems, traffic is redirected to others to minimise downtime
  • Resources such as CPU, memory and storage are allocated dynamically, based on demand, to optimise performance
  • Data is copied across multiple servers or locations, so a hardware failure doesn't mean data loss

Cloud computing 14.4

Cloud computing provides on-demand access to a shared pool of computing resources over the internet, including storing data on remote servers maintained by third-party companies. Access is usually through a web browser, sometimes over a VPN for a secure connection. Because the resources are location-independent, they can be accessed from anywhere with an internet connection. The resources are shared between the client company and the provider, and the provider can scale them up or down dynamically as needed, without the client having to do anything.

Service models

ModelWhat it provides
Infrastructure as a Service (IaaS)The provider hosts network resources that businesses use directly, such as servers, storage and networking, accessed over the internet.
Platform as a Service (PaaS)The provider hosts a platform (a development environment) that businesses use to build and run their own software applications.
Software as a Service (SaaS)The provider hosts complete software applications and makes them available to users over the internet.

Cloud resources can be scaled up or down quickly to match changing demand — this elasticity means computing resources are always available to meet varying workloads.

Uses of cloud computing

  • Storage and backup
  • Web-based email services, custom mail domains, and access to email from anywhere with an internet connection
  • IaaS: renting virtualised servers, storage and networking, removing the need to own that hardware
  • PaaS: building and running software on an online platform, without worrying about the underlying technical setup
  • SaaS: using software applications over the internet, without installing, maintaining or updating them locally
  • Connecting and managing smart devices, such as thermostats and cameras, online

Advantages

  • No need to buy extra hardware to store data and software
  • No need to host a development platform to build software
  • No need to employ technical staff just to maintain the hardware behind the provider's service
  • Backups are handled automatically by the cloud provider
  • Data and applications can be accessed from anywhere with an internet connection
  • Performance can be scaled up quickly for a temporary surge in demand (e.g. a sale), then scaled back down afterwards to save cost

Disadvantages

  • Reliant on a third party to keep data secure, with little control over their actual security measures
  • If a cloud provider's resources fail — for example, a server goes down — the data or software on it becomes unavailable
  • Cloud resources can only be reached with an internet connection, so no connection means no access
  • The data owner may not know exactly where their data is physically stored, and so may be unaware it's held in another country
