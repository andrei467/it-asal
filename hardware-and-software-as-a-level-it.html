Cambridge AS & A Level IT · Hardware and Software

Hardware and Software

This page covers the computers that run large organisations and scientific research, the system software that operates a computer, the utilities that maintain it, the choice between custom-written and off-the-shelf software, and the different ways users interact with a system.

Hardware and software Introduction

Hardware

Hardware devices are the physical components of a computer, made of electronic components. Examples are the CPU, motherboard, RAM, graphics card, secondary storage, monitor, keyboard and mouse.

Software

The programs and apps on a computer are called software — programs that give instructions to the computer. Examples include word processing, spreadsheet and anti-malware programs. The operating system, the specific software that manages the hardware within a computer system, is also software.

Software programs give instructions to the computer so that it can carry out a task. The instructions are sent to the CPU in binary, which is made up of ones and zeros (for example, 10101110 11101101).

Mainframe computers and supercomputers 2.1

Uses of mainframe computers

A mainframe computer is a powerful computer serving several terminals. It can serve many thousands of terminals within an organisation. A terminal is a computer connected to the mainframe, often with very little processing power and memory of its own, for example a basic computer or an ATM.

  • Hosting business databases that businesses and consumers access at the same time through a web interface
  • Large-scale transaction processing and batch processing
  • Industry statistical analysis, such as analysis of census data, and consumer statistics such as trends and spending analysis

Uses of supercomputers

A supercomputer is a large computer with parallel processing, designed to carry out large numbers of complex calculations very quickly. It runs a few programs and executes instructions as quickly as possible for one purpose, using its full power to solve single problems. Parallel processing allows many instructions to be executed at the same time.

  • Physics simulations — quantum mechanics is mathematically complex and computationally demanding to simulate. Supercomputers let scientists model these systems with great accuracy and detail.
  • Medical science — simulating the properties of new drugs and materials at the atomic level, supporting more efficient medications and the treatment and identification of current and new diseases.
  • Environmental models — numerical models of the atmosphere, ocean and space, processing billions of observations from weather stations, satellites, balloons, buoys and radar.
Did you know?

In 2022, the most powerful supercomputer reached 1,102 petaFLOPS — 1015 floating-point operations per second, more than 1000 times faster than an average home computer.

Characteristics of mainframes and supercomputers

Longevity is how long a mainframe will last before it is replaced. They cost a lot of money, so they are used for many years. Being able to upgrade them with extra processors or memory helps them cope with increasing demand.

Reliability, availability and serviceability (RAS) means they are designed to be used 100% of the time:

  • Reliability — hardware components can self-check and recover automatically after a failure. Software is tested extensively and can be updated quickly if problems are found.
  • Availability — the mainframe must be able to operate at all times. Extra components such as storage and power supplies take over automatically if an active one fails. This is redundancy: spare components in readiness to take over.
  • Serviceability — a failed component can be replaced without affecting operation. Hot-swappable components can be replaced while the system is running. Serviceability also measures how quickly a mainframe can be repaired if it has to be shut down.

Mainframe security

Mainframes service many applications and thousands of users at once, so they need a multi-layer approach to security including identifying users, authentication and access control. Individuals and groups are given permission to access different resources, each with different levels of access. For example, web users can see descriptions, images and prices of active products, but only product managers can see non-active products or change descriptions and prices. Security software also monitors for threats and alerts administrators if one is suspected.

Performance metrics

MIPS (millions of instructions per second) is usually used to measure mainframes. It is not considered accurate because these factors affect processing speed:

  • A complex instruction can take longer than a simple one. CISC (complex instruction set computing) processors have single instructions that do many things; RISC (reduced instruction set computing) processors have single instructions that do very little but manage them efficiently
  • Workload mix
  • Memory and cache sizes
  • Amount of input and output activity
  • Operating systems and software
  • Changes made to hardware

Despite this, the cost of mainframes is generally based on the maximum MIPS they can achieve.

FLOPS (floating-point operations per second), or MFLOPS (mega FLOPS — one million per second), is used to compare supercomputers, because floating-point instructions are used in scientific computational research. It is more reliable than MIPS, but some processors can do in one floating-point operation what others need several for. For example, the Cray-2 has no divide instruction but the Motorola 68882 has divide, square root, sine and cosine, so the Cray-2 needs several instructions to divide.

Larger memory and cache sizes can make a significant difference to mainframe performance.

Input, output and throughput

A batch workload that operates sequentially uses resources efficiently, but online activity such as web access has much more random resource requirements. Lots of input/output activity makes processors less efficient, because tasks are suspended while input/output interruptions are processed. System assist processors (SAPs) can handle input/output requests, freeing the main processors from interruptions. Enhancements or bug fixes to operating systems and applications can improve efficiency or have an adverse effect.

Operating systems and fault tolerance

  • z/OS — general purpose, offering a stable, secure and continuous environment
  • z/VM — specialises in virtual machines, each running its own operating system
  • z/TPF — specialises in transaction processing with high volumes of transactions, such as ticket sales
  • Most supercomputers run an operating system based on Linux, which is open source and so freely available for development

The operating system for a supercomputer or server is more advanced than a desktop one. It must deal with fault tolerance, manage software processes across many more processors and manage computers on a client/server system.

Fault tolerance is how far a server is resistant to failure. Hardware failure is dealt with using redundancy. Software and data failure is dealt with by copying data to many different disks or storage devices, so the server can use the back-up disks if the main data store fails.

Number of processors and heat

The more processors a server has, the more processes it can run at the same time. The number of threads each core can run and the clock speed also matter. A server with more cores will usually run faster.

Mainframes and supercomputers generate a lot of heat, so cooling is needed:

  • Air cooling — fans blow hot air away and replace it with cooler air. It uses a lot of power, so many data centres are being built in colder parts of the world where natural cold air can be circulated.
  • Liquid cooling — more efficient. A plate on the back of the processor has cool liquid on the other side, transferring heat from the processor to the liquid, which is pumped through a cooling radiator.

Advantages and disadvantages

Advantages

  • Designed to be reliable, available and serviceable
  • Scalable — processors and memory can be added
  • Designed to last for at least 10 years
  • Can store and process extremely large amounts of data
  • More than one operating system can be used at once, which can improve performance
  • Hardware failures are notified immediately so replacements are quick
  • Terminals only need input and output devices; connected desktops can use their own power for small tasks

Disadvantages

  • High cost, so only used by large organisations such as governments, banks and corporations; specialist operating systems are also expensive
  • A lot of space is needed and the temperature must be controlled
  • Specialist support staff are required
  • The interface is command driven, which can be hard to understand
  • Supercomputers process big data, so they need massive external storage that reads and writes quickly enough

System software 2.2

System software is the software needed to operate a computer system. The software that operates the hardware is the operating system.

Operating systems

An operating system manages the hardware. When the computer is turned on, the BIOS (Basic Input/Output System), stored on ROM on the motherboard, loads first, then loads the operating system. The operating system is the first software to load and links the hardware to applications software, managing communication between the two. It manages hardware by:

  • Allocating memory to software
  • Sending data and instructions to output devices
  • Responding to input devices, such as when a key is pressed
  • Opening and closing files on storage devices
  • Giving each running task a fair share of processor time
  • Sending error or status messages to applications or users
  • Dealing with user logons and security

Device drivers

A device driver is the software that comes with an external hardware component and sends customised instructions to that specific component. Operating systems often include common drivers, for example for basic graphics or printing. With common drivers, applications can issue generic commands such as 'print' to the operating system without needing the different instructions for every make and model of hardware.

Translators

A translator translates a program written in a high-level programming language into machine code the computer can understand.

Compilers

A compiler translates a high-level language into an executable file of machine code (also called the object file). The original file is the source file. The whole source code is translated at once, and the executable can then be distributed. It only runs on operating systems it was compiled for — a program compiled for Windows will not work on Linux unless compiled again.

Compilation has three stages:

  1. Lexical analysis — white space and comments are removed and the code is broken into tokens, each representing a keyword, constant, identifier, string, number, operator or punctuation symbol. Some tokens are replaced by shorter ones (for example ENDWHILE by EW). Errors found are reported to the user.
  2. Syntax analysis — the structure is checked against the syntax of the language. A dictionary is created listing the variables used, their data types and the memory location to use.
  3. Code generation — the source code is converted into machine code for the target machine type. Different machine types need different machine code.

Interpreters

An interpreter translates and executes a high-level program one line at a time, translating each line into an intermediate stage and then executing it, reporting errors as each line is translated. It can be less efficient than a compiler because translating takes time during execution and statements inside loops (FOR, REPEAT, WHILE) are analysed each time round. Interpreters are often used for macros and application-based script languages (such as Visual Basic for Applications), useful when a document needs to be opened on a variety of operating systems, and for testing so that parts of a program can run without compiling the whole thing.

Java uses both: source code (.java) is compiled into Java bytecode (.class), an intermediate code. A Java Virtual Machine on the computer interprets the bytecode at execution time so the program works on any operating system.

Cross compilers

A normal compiler only creates code for the system it is installed on. A cross compiler can make executable code for other systems, so software can be developed for systems with different architectures, such as Android or iOS. It is useful for machines with limited processing power that cannot run a compiler, for example the small CPU in a car's electrical system: the programs are written on a more powerful machine, compiled with a cross compiler and transferred to the car's ECU.

Linkers

Programs often consist of several modules, each compiled into a separate object file. A linker (link editor) combines the object files into a single executable file. It can also link modules from a common library — code for common tasks such as mathematical functions, memory management, open and save dialogues, progress bars and input/output. A linker can select which modules form part of the executable, as not all are always needed.

Advantages and disadvantages of system software

Advantages

  • Many different types of software to choose from for different tasks
  • Many companies make software for the same task, giving choice over cost and features (for example Microsoft and Google word processing)
  • Software can be removed and updated as needed
  • Many devices come with a range of free system software
  • A wide range lets you customise your device to your needs

Disadvantages

  • May be hard to find software that does exactly what you need
  • May need a lot of research to find the best software for the right cost
  • Needs to be kept updated to stay secure and gain new features
  • Can be very expensive
  • Free software may lack the support and function you need
  • Choosing correctly needs some technical understanding

Utility software 2.3

Utility software is system software that performs maintenance on the computer system. It does not include the operating system, but an operating system may come with utility software pre-installed.

Anti-virus

Anti-virus software is sometimes called anti-malware software, as it also deals with threats such as adware and spyware. It has two main functions:

  • Anti-virus monitor — continually monitors the system and prevents unusual behaviour or signs of viruses or malware from being executed.
  • Scanning — checks for viruses or malware already on the system. The user can usually choose to disinfect, quarantine or ignore.
OptionWhat it does
DisinfectSafest — completely removes the threat, but any affected data or program is deleted
QuarantineThe compromise — a safe area where the malware cannot be executed, and the data or program stays isolated until it can be checked
IgnoreVery dangerous — the malware may run with unexpected results

Back-up

Back-up utilities create a second copy of data and programs in storage. A back-up can be run by the user when asked, or scheduled to run automatically at a set time. The user can usually select which folders and files are backed up and where the back-up is stored.

Data compression

Compression utilities reduce the size of files so they use less storage. It can be done file by file, or for a set of files or folders. A compressed file is slower to open than an uncompressed one, but as it is smaller it uses less storage and transfers more quickly. Compressed files must be uncompressed before they are edited, which takes time and can make the computer appear slower.

Did you know?

Compressing files is often called "zipping", because compressed files were stored as .ZIP, for example MySmallFile.zip.

Disk defragmentation

A hard disk drive (HDD) has the device (the electronics) and the disk (the medium that stores data). A read-write head at the end of an access arm magnetises sectors on the disk (platter).

  • There is usually more than one platter, with several read-write heads for each side of each platter.
  • Each platter has tracks, and each track is split into sectors.
  • Tracks in the same position on each platter form a cylinder.
  • The computer tries to store data in clusters on a single cylinder, which needs the least access arm movement. Moving the access arm is the slowest part of accessing data, so less movement means quicker access.

Fragmented files

Files are first kept together on the same or adjacent cylinders. When files are deleted, gaps are left. If a file grows, it uses more space. Once all the cylinders are used, the only free space is in the gaps; if the gaps are not big enough, files are split across gaps and become fragmented. To open a fragmented file, the access arm must move to different locations to read the whole file, which makes opening it slow.

Defragmentation

A defragmentation utility reorganises the files so that each file is contiguous (kept together). It moves fragmented parts of files and small files into free space, creating space on whole or adjacent cylinders, then moves the files so each is together. This can significantly improve performance, especially if program files have become fragmented.

Formatting

A new disk must be formatted: the tracks are organised into sectors, where data will be stored. Formatting a used disk loses all its data.

Partitioning

A hard disk can be split into smaller parts — for example a 300 GB disk into three 100 GB sections. Each section is a partition, with its own file storage system and a unique drive letter such as G or J. It can create separate stores for different people: a teacher might use the G drive for school policies while students use the S drive for class work, both on the same storage device.

File management

File management utilities give more control over which files are copied and deleted, and how. For example, copying only word processing documents from a series of folders into a single destination folder. Files can also be synchronised across locations or computer systems, so a change in one is updated in all others.

  • Some utilities can delete files and folders locked by the operating system.
  • Normal deletion leaves the data on the disk, only hidden from the user. Deleting utilities can delete files permanently so they cannot be restored or accessed.
  • Some remove temporary files no longer needed, or files left behind after a program is uninstalled or a user profile is removed.

Disk management software

Allows maintenance and operations on storage devices: partitioning and formatting the disk (both high- and low-level), renaming drive letters, scanning for errors and changing the file system.

Custom-written and off-the-shelf software 2.4

Custom-written software

Custom-written software is written to meet the specific requirements of a client. It is customised to the client's needs and would not be useful to other individuals or organisations, as it only carries out that specific task. Examples:

  • Robots in manufacturing — specific software to control custom robots
  • Specific scientific experiments — specialised software to process the experiment's data
  • Autonomous vehicles — software controls vehicles from different manufacturers; Ford software would not work on a Toyota or a Tesla

Off-the-shelf software

Off-the-shelf software is general purpose software that already exists and is available to a large market, bought online or from a shop for a specified price. Examples are word processing and financial software. Writing documents always uses similar features such as spell checks and changing fonts.

Choosing between them

  • Degree of testing — custom software may be less tested because fewer people use it, so bugs are found more slowly.
  • Level of support — more support is likely for off-the-shelf software because more people buy it, giving the manufacturer more money to spend on support.
  • Cost — custom software costs a lot more because only one client wants it; off-the-shelf costs are shared across many customers.
  • Adaptability — both can be adapted, but custom software more easily, because changes affect a small number of users. Changing off-the-shelf software affects millions of users, so it may take longer.

Proprietary software

Proprietary software is owned by an individual or organisation who sells it for use under an agreed licence. Only the files needed to run it are provided; the source code stays with the owner. Licences include freeware, shareware, single user, multi-user and site licence. For example, an office suite could be sold for business use on a single computer, or for personal use on up to five devices. Freeware and shareware can often be used free of charge, but some features may be restricted or it may stop working after a trial period until payment is made.

Open-source software

Open-source software has its source code freely available — the source code must be distributed with the executable version. It can be freely accessed, used, changed or shared. There is often a community of developers contributing to it. It is often free, but sometimes there is a fee.

User interfaces 2.5

A user interface is the way a user communicates with a computer system or piece of software, allowing them to interact with it.

Command line interface

A command line interface (CLI) lets the user enter text commands, and the system responds with text. For example, the user changes directory (cd logs), lists it (dir) and copies a file (copy directx.log f:), then gets a confirmation message that one file was copied. The only prompt is the currently active directory.

CLIs use very little memory and are useful in old systems, for maintenance of very small systems such as engine management systems, and for technical users doing complex operations that user-friendly interfaces cannot. However, they are difficult to learn because users must remember all the commands, and errors are easily made.

Graphical user interface

The most common interface, found on desktops, tablets, phones, televisions, set-top boxes, photocopiers and in-car entertainment. GUI elements are remembered with the acronym WIMP:

ElementDescription
WindowsAn area of the screen for a specific task, such as an application, a file or a print dialogue box
IconsAn image representing a program, file or task, which can be selected to open it
MenusWords on screen representing a list of options that can expand into sub-menus
PointersRepresents movement from a pointing device such as a mouse or a finger on a touch screen, and selects and manipulates objects

Complex GUIs may need a lot of memory; simple GUIs can be used where memory is limited, sometimes instead of a CLI in small embedded systems. Simple web-based GUIs are commonly used to maintain routers, switches and printers.

GUIs are often easy to use because commands are shown as pictures and menus offer selectable options. They can be restrictive for technical users who must navigate menus when they know the command they want. Shortcuts — key combinations such as Ctrl+C to copy and Ctrl+V to paste — help solve this.

Dialogue interface

Users speak to the computer and it carries out the command, perhaps responding with a synthesised voice. Popular on mobile phones and in-car systems (for example 'Temperature 20', 'Call home', 'What is the time?'). Some automated telephone systems recognise a user's voice, so the keypad is not needed. No physical interface is needed, so it suits home automation (lights, entertainment systems, shutters), and anybody in the room can control a television without a remote. Words can often be spoken faster than typed.

The main problem is recognising the voice: accents, different voices, language and background noise (such as a car's engine) all make it hard. Users must also know which commands are understood, so some systems prompt with options. Systems cannot understand requests in any format.

Gesture-based interface

Recognises human motion, such as tracking eyes and lips, hand signals or whole-body movement. The original Nintendo Wii mimicked hand movements with a handheld controller; Microsoft's Xbox can track whole body movement without devices being held or worn. Hand gestures on mobile devices can control objects on screen, such as a swipe to close a program or a pinch to zoom out. Avoiding screen contact helps control infection, for example in an operating theatre. Gestures can be essential for users with physical disabilities — someone with no control from the neck down could control a computer with their eyes.

The biggest problem is accuracy: it needs highly accurate cameras or sensors, which is why many virtual reality applications still use sensors attached to the body. Controlling a pointer with a finger in mid-air is also difficult.
