Cambridge A Level IT · Chapter 14

Networks and Infrastructure

This page covers what networks are and the types of network, the components and servers they use, cloud computing, and how data is transmitted across networks.

Networks 14.1

Before the 1990s, most computers were not connected to other computers. Since then it has become very common for computers to be connected to networks — two or more computers or devices connected together so they can communicate and share data and resources. Now nearly every computer is connected to at least one network. The simplest network is two computers connected, but most are much larger and more complex. Two laptops sharing the same Wi-Fi are a network, and every computer connected to the internet is also part of a network. The primary reason we create networks is to share data and resources, and to communicate with other people.

Characteristics of networks

Each network has its own characteristics: its topology (the arrangement or pattern in which all devices on a network are connected), its architecture (the layout of a network, both logical and physical) and its protocols (a set of rules that determine how computers on a network communicate with each other).

Topologies (physical and logical)

Any device connected to a network is a node. A network's topology is the arrangement of nodes within a network. Every network has both a physical and a logical topology.

Physical topology is how the nodes are physically connected to each other. There are four common types:

TypeDescription
BusAll the nodes are connected directly to a central cable that runs through the network, called the backbone. Data is sent up and down the central cable until it reaches the correct node.
StarAll nodes are connected indirectly through switches. All communications are passed through the switch or switches in the topology.
RingNodes can only connect to the two nodes on either side of them. This creates a single pathway for data to travel, and the topology resembles a circle.
MeshPopular because it is efficient. In a full mesh every node is connected to every other node, so data can be sent across many different routes.

Figures 14.3 to 14.6 redrawn: the four common physical topologies.

Logical topology is how data flows through a network. It is bound to a network protocol that determines how nodes communicate with each other, and refers to the different roles the nodes play, determined by the protocols and the architecture. Two networks could share the same physical topology but have different logical topologies. Depending on how you set up a network, a node could be a client or a server. Think of a house: the rooms are always the same size and in the same place, but you could swap which room is your bedroom — the room does not change but its function does.

Protocols are instructions for how different computers in a network communicate with each other. For example, all computers communicating via the internet use the Internet Protocol (IP). Architecture refers to the physical and logical layout of a network, including transmission equipment, infrastructure (wired or wireless), software, communication protocols and the transmission of data between nodes. Network architecture is the complete layout of the network, whereas the protocols and topologies are part of the architecture.

Types and uses of network

  • local area network (LAN)
  • wide area network (WAN)
  • client–server
  • peer-to-peer
  • virtual private network (VPN)
  • mobile networks

LAN and WAN

A local area network (LAN) is a relatively small network within a single building or site, such as a home, school or small business. It could be as simple as two computers in a home or as extensive as 100 computers, peripherals, switches and servers in a small business. A wide area network (WAN) is a relatively large network, normally two or more LANs that are linked, over a large geographical area. The largest example is the internet. Businesses such as banks and the police use WANs because they have multiple branches or offices over a large area that need to share data and resources.

Client–server

A client–server network contains two types of computer. A server is a computer that is a central point of control and provides a dedicated function such as print server for the network. All other computers are clients, which are not a central point of control, and are all connected to the server to allow it to perform its dedicated function. Most downloadable content (such as videos, games or software) comes from a client–server network.

Peer-to-peer

A peer-to-peer network contains computers known as peers, which are of equal importance. It can be as simple as two computers in a household or can contain hundreds of peers connected using the internet. The main reason these networks are created is to share data. It has a decentralised structure: there is no central point of control (for example Skype), so each peer has the same level of responsibility and capability.

Each user stores data on their own computer and can choose to keep it private (other peers cannot view it) or make it public. If a peer has a peripheral such as a printer attached, the user can make it public so other peers can use it. Peer-to-peer networks can share large files such as audio, software and videos, using dedicated peer-to-peer software that links people who have the files with people who want them. This method has been controversial because of its use in the piracy of music and movies, but some companies use peer-to-peer to distribute their software, which users often pay for.

BitTorrent is a communications protocol often used in peer-to-peer file sharing, which allows the transfer of large files such as videos by distributing the load of downloading across several sources. Several sources (hosts) are collated to create a swarm. Each host is given pieces of the file, and the protocol downloads the pieces simultaneously from various hosts in the swarm and rearranges them to create the completed file. For example, ten hosts may have 10% of a movie file each: the protocol downloads all ten parts at once and puts them back together. Each piece is protected so users cannot modify it. Each user trying to download the file is a peer, and each user providing an upload as part of the swarm is a seed.

Virtual private network (VPN)

Individuals or organisations may want to access sensitive data from a remote location, far from where it is stored, and a request could be intercepted by a hacker. A VPN overcomes this. The user opens their VPN client, the software used to create the VPN. The software encrypts any data the user wants to transmit before it is sent across the internet. The data is first sent to the VPN server and from there to its destination. When the data arrives it only shows that it was sent from the VPN server, not the details of the original sender.

How a VPN works: data is encrypted before it crosses the internet, and the VPN server forwards it on the user's behalf.

Without a VPN, data could be intercepted and the contents of the data packets examined. This would show who sent the data and where it is going, so a hacker could use it to hack the user's accounts. Security is increased in several ways by using a VPN:

  • The data is encrypted, so even if it is intercepted it will be meaningless.
  • If a VPN tunnel (a protocol that allows data to be moved securely between networks by repackaging it into a different form) is used, the connection is also encrypted, so it would be very difficult to trace that you have connected to a VPN at all.
  • If the data is intercepted between the user's computer and the VPN server, a hacker would not know the final destination.
  • If the data is intercepted between the VPN and the final destination, the hacker would not know who the original sender is.

Mobile networks

A mobile network (also called a cellular network) is a wireless WAN that uses radio to transmit and receive communications from portable devices such as smart phones. Mobile networks now cover most of the world's regions.

Did you know?

Over half of the world's population has a mobile phone, which is around 4 billion people.

Advantages and disadvantages of types of network

Client–server

Advantages

  • Files can be located in a single place and regularly backed up, so users do not need to be responsible for this
  • Security can be controlled from a central point
  • Levels of access can be applied to resources and data on the servers, which is very beneficial when data must be kept confidential
  • Updates for software or peripherals can be rolled out from a central location

Disadvantages

  • Can be very expensive to set up because of the need to buy expensive equipment such as servers
  • Expensive to maintain, as specialist knowledge is required to set up and maintain the servers
  • Failure of a server means functionality is unavailable for all users, for example no user can access their files if a file server fails

Peer-to-peer

Advantages

  • Relatively cheap to set up, as there is no need to buy expensive servers
  • Requires little technical knowledge to set up
  • Users are able to share data and resources
  • Often has less traffic than client–server
  • Users have full control over the data stored on their computer
  • If a peer fails, there is only a minor effect on the rest of the peers

Disadvantages

  • If a peer computer is being accessed by another peer, it can slow it down
  • Data on each peer is not centrally backed up, so if a peer loses data it is lost for everyone unless a copy is saved locally
  • Public files may be disorganised and difficult to navigate, because there is no central organisation system
  • Each user is responsible for the security of their own peer; a virus could be passed to other peers

Virtual private network (VPN)

Advantages

  • Data is encrypted before it is sent across the network
  • The identity of the sender is kept private from the destination and from any hacker who intercepts the data
  • The maintenance of the VPN server is not the responsibility of the user

Disadvantages

  • In some countries the use of a VPN is illegal or controversial, as it can create anonymity in criminal activity
  • The security of the data relies on a third party and their software and maintenance of the VPN server
  • There is often a cost, such as a monthly subscription fee

Mobile networks

Advantages

  • Users can communicate and access the internet while on the move
  • Breaking the network into cells allows lower power radio transmitters, bringing energy and cost savings
  • Frequencies can be split among neighbouring cells and reused in more distant cells, so more communications can take place at the same time
  • Larger areas can be covered by using several low power transmitters
  • The use of multiple transmitters makes the network stronger: failure of one base station only affects one cell

Disadvantages

  • Quality of reception can vary and can be poor towards the edge of a cell, leading to interrupted or delayed transmissions
  • The use of frequency must be carefully planned to avoid interference between cells
  • The technology for 5G is limited at present and could take a while and be costly to make fully useable

Components in a network 14.2

Network interface cards

The first component a device needs to connect to a network is a network interface card (NIC). It can allow a wired connection, but also exists in wireless form as a wireless network interface card. It is an electronic circuit board inserted into a device's motherboard; modern devices often have it built into the motherboard.

The manufacturer also provides the card with a media access control (MAC) address, unique to the network interface card and made up of the manufacturer's ID and the serial number. It is used to uniquely identify the device on a network. An ethernet cable connects into a port on the card and can be connected to another computer, or to a component such as a router (which uses a computer's IP address to send data packets to a destination outside the current network) or a switch (which uses a computer's MAC address to send data packets to a destination within a network). With a wireless card, no cable is needed.

Hubs and switches

If only two computers are connected, a simple ethernet connection between the two can be made. If several computers need to be connected, a component is needed to connect them and manage the traffic: a hub or a switch.

A hub joins computers together and forwards data packets to all connected devices. The hub receives the data and forwards it to every other device connected; devices ignore data if they are not the intended destination. A hub may be passive (just sends the data on) or active (amplifies and regenerates the signal to make it stronger). Because a hub forwards data to all devices, there is a lot of unwanted traffic, which can cause data collisions. The switch was developed to overcome this.

A switch connects devices in the same way, but it can examine each data packet and forward it only to the intended destination. When devices are connected to the switch, it creates a MAC address source table; when it receives a packet it looks at the destination MAC address and forwards it to that device. This reduces traffic and the number of data collisions.

Figures 14.13 and 14.14 redrawn: a hub forwards data to all devices, a switch forwards it only to the intended device.

Repeaters

Signals may deteriorate (get weaker) as they travel around a network, for example because of interference in the transmission media. A repeater boosts the signal as it passes through, and can be used at various points. It can boost a wired or wireless signal and can retransmit both analogue and digital signals.

Wireless access points

A wireless access point receives and transmits radio signals to allow Wi-Fi connection to a network. It allows a wireless device to connect to a wired network: it receives wireless signals and uses the wired network to transmit them to their destination, often via a switch. It often has a limit of 15 to 20 devices, so larger organisations have several distributed throughout the building. Signal strength also deteriorates with distance.

Bridges

An organisation may be based in different buildings on the same site, which splits up its LAN, and the signal can deteriorate too much between devices. A bridge connects segregated parts of a LAN. It uses MAC addresses to forward data, like a switch, but examines packets against the MAC address source table: if the destination is in another part of the network it forwards the packet 'across the bridge'; if the destination is within the same part, it ignores the packet and lets it continue to its destination.

Gateways and routers

Businesses such as banks may have several branches, each with its own LAN, and want to share data. LANs can be connected using a gateway, which joins different LANs together. A common gateway component is a router, used to connect LANs together and to connect LANs to WANs. One of a router's primary roles is to assign each connected device an IP address, a unique address for each node on a network that identifies its location in the network.

A router acts like a switch, with two main differences. A switch only forwards packets within a single network, while a router forwards packets outside the current LAN to other networks. And a switch looks at the MAC address of the destination, while a router looks at the IP address of the destination device.

There are several types of server that could be included in a client–server network. Each performs a dedicated function.

The role and function of servers

Servers can be grouped together to provide functionality that would not be possible with a single computer. Servers grouped in the same location are called a server farm. As a group, they have a huge amount of processing power and can execute very large tasks, as all servers can be used to execute one or more parts of the task at the same time. There are often thousands of servers in a server farm.

Did you know?

One of the largest server farms is owned and maintained by Google. It has more than 10 000 servers.

The operations of servers in a network

Most client–server networks operate using a request and response method of communication between servers and clients. A client sends a request to a server to ask it to perform a task, and the server responds by performing the task — a bit like asking a restaurant server for something, and being served.

Cloud computing 14.4

Cloud computing is the use of a network of servers hosted on the internet to store and manage data. It offers individuals and organisations a range of internet services, such as storage of data and software, and access to resources such as servers. Examples of providers include Dropbox and Google Drive. Some cloud computing services are free to users; others may be subscription or usage based.

Levels of service

  • Infrastructure as a service (IaaS): the provider hosts some of the network resources used by businesses, such as servers. Businesses gain access to these resources using the internet.
  • Software as a service (SaaS): the provider allows users access to the provider's software applications.
  • Platform as a service (PaaS): the provider hosts platform resources that can be used to build software applications. Users gain access to these resources using the internet.

Uses of cloud computing

One of the most common uses by individuals is to store data. Many applications now store data linked to the application, and other personal data, on cloud resources, normally a collection of servers in a remote location. In organisations, several people working on the same project can access the same data, which makes version control and co-working much easier. Cloud computing is especially useful for new or small businesses that may not have the capital to invest in hardware and want to use free or cheap software.

Advantages and disadvantages

Advantages

  • No need to purchase additional hardware to store data and software
  • No need to host your own development platforms to develop applications software
  • No need to employ technical staff to maintain the hardware
  • No need to create a back-up, because this is automatically carried out by the cloud provider
  • Data and software can be accessed from anywhere in the world with an internet connection
  • No need to worry about updating software accessed using the cloud, as the provider does it
  • Organisations can quickly boost network performance by employing more resources from the cloud, for example increasing the capacity of a web server for an online sale, then reducing it again afterwards to save costs

Disadvantages

  • Users rely on a third party to keep their data secure and have little control over the security measures
  • If the provider's resources fail, for example a server, the data or software stored on it becomes unavailable
  • Resources can only be updated or refreshed when connected to the internet, so with no connection they cannot be updated

Data transmission across networks 14.5

Speed of transmission

Bandwidth is the range of frequencies available for a communication method, which determines the transmission rate. It is a measure of the frequencies available on the channels of communication in the network, and is also used to describe the maximum amount of data that can be transferred across a network within a given time, usually one second. The more bandwidth a connection has, the more data it can transfer at a single time. Remember that bandwidth is a measure of frequencies, not a measure of speed.

The bit rate is the rate at which bits can be transferred in data transmission — how many bits are transferred in a given period of time. Bandwidth describes the performance ability of a network, whereas bit rate describes the rate at which a particular file, such as a video, is transferred. The bit rate will not exceed the bandwidth, because the bandwidth is the maximum possible bit rate. For example, a network could have a bandwidth of 100 Mbps but a video file transferred over it might have a bit rate of 75 Mbps.

Data streaming

Bandwidth and bit rate are important when streaming audio and video. When a file is streamed, either live (real time) or on demand (not live), there is no need to download and store the whole file before it is played. Data is streamed as a series of bits to the receiving device, which has a temporary storage area called a buffer. Data is stored in the buffer as it is downloaded, before it is needed. Data is removed from the buffer to be played and at the same time more is added, ready to play when required.

Streaming: data is added to the buffer as it downloads and removed to be played at the same time.

Properties of different transmission methods

A wired or wireless connection is needed to connect devices in a network. The three main types of wired connection are fibre optic cable, copper cable (coaxial and twisted pair), and lasers (which travel through the air).

Effect of the medium on the available bandwidth

Fibre optic has significantly more bandwidth than copper cables, but lasers have an incomprehensibly high bandwidth, so how fast you can transmit data depends on the method of transmission. You could send large photo files very quickly via a laser, but it could take minutes or hours with copper cables.

The bandwidth available also limits the quality of audio or video that can be streamed. For example, with a bandwidth of 2 Mbps a user is unlikely to be able to stream an ultra-high definition (4K) movie, because the data required to produce each frame would be too much for the bandwidth available. A bandwidth of 32 Mbps is generally required to stream an ultra HD movie.
